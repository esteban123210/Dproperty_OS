## DESIGN GUIDELINES FOR ALL SLIDES

### Color Palette (Wes-Anderson Inspired)
- **Primary:**
  - Cream white: #F9F7F0 (background)
  - Butter yellow: #F4D03F (accents, highlights)
  - Powder blue: #B4D4FF (secondary accents)
  
- **Secondary:**
  - Dusty pink: #D4A5A5 (warmth)
  - Soft orange: #F5B041 (energy)
  - Olive green: #6B8E23 (nature)

### Typography
- **Headlines:** Serif font (elegant, readable) — Size 44–54pt
- **Body text:** Clean sans-serif — Size 24–32pt
- **Quotes:** Handwritten-style font — Size 32–40pt
- **Numbers/Data:** Bold sans-serif — Size 28–36pt

### Layout Principles
- ✅ Symmetrical framing (mirrors video aesthetic)
- ✅ Generous whitespace (breathing room)
- ✅ Maximum 3 colors per slide
- ✅ Minimal text (visual-first approach)
- ✅ Consistent alignment (clean, intentional)
- ✅ One key idea per slide

### Images & Visuals
- Use: Soft, warm photography (Paris cafés, bohemian spaces, plants, natural light)
- Avoid: Corporate stock photos, harsh lighting, clutter
- Include: Handwritten elements, botanical details, woven textures
- Aesthetic: Magazine-quality, intentional, curated

### Transitions
- Keep simple: fade or slide (not distracting)
- Timing: Normal (don't rush)
- Consistent throughout

### Speaking Notes (For Presenter)
Add speaker notes to each slide with:
- Key talking points
- Time allocation (2–3 minutes per major section)
- Pronunciation of French locations
- Emphasis points

## HOW TO CREATE THIS IN PowerPoint

### Step 1: Set Up Slide Master
1. Open PowerPoint
2. Go to View → Slide Master
3. Create custom background with cream color (#F9F7F0)
4. Set default fonts: Serif for headlines, Sans-serif for body
5. Add footer with presentation title

### Step 2: Create Slides
1. Copy title for each slide from outline above
2. Paste content into slide
3. Add images/visuals matching design guidelines
4. Use color palette consistently

### Step 3: Add Design Elements
- Insert shapes (circles, lines) in brand colors
- Add icons or simple illustrations
- Use images with consistent editing (same warmth/tone)
- Maintain margins and alignment

### Step 4: Polish
- Proofread all text
- Check image quality
- Ensure consistent sizing
- Test on projector/screen
- Practice presenting

### Step 5: Add Transitions
- Select all slides
- Add simple fade transition (0.50s)
- Don't animate text (keep it clean)
