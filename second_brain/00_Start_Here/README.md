# 00_Start_Here — Navigation and Memory

**The question this folder answers:** *Where do I begin? What did we decide?*

## Open these, in order

1. [[Vault Architecture Map]] — **where everything lives**. Read once, then whenever you cannot find something.
2. [[../01_Canon/00 - Precedence and Canonical Reconciliation]] — **what wins when records conflict**.
3. [[Project Context Brief]] — the company and products in two pages.
4. [[Current Priorities]] — what matters now.
5. [[../11_Execution/Deliverables Tracker - Compact MD]] — what exists and its status.

## What lives here

| File | Purpose |
|---|---|
| [[Vault Architecture Map]] | Folder-by-folder definition of the vault; old→new path mapping |
| [[Master Index]] | Link hub to every area |
| [[Project Context Brief]] | Company, products, boundaries, pricing, what is retired |
| [[Decision Log]] | Decisions that must not be accidentally re-opened |
| [[Open Questions]] | What is genuinely undecided, grouped by area |
| [[Current Priorities]] | P0/P1/P2 and the 90-day gate |
| [[Vault Manifest]] | Change history and per-folder status |
| [[Source Map]] | Canonical sources and outstanding research |
| `AI Handoff Pack/` | What to upload when starting a new AI chat |
| `Meeting Notes/` | Session closeouts |

## Rules

- **If it matters, it must be saved here or in the tracker.** Chat history is not memory.
- Decisions go in the Decision Log with a date, reason, impacted areas and status.
- Superseded material goes to `98_Archive/`, never deleted.
- Every material claim carries a truth label: `[F]` `[D]` `[M]` `[A]` `[T]` `[R]`.
