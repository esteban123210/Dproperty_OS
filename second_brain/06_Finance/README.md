# 06_Finance — The Numbers

**The question this folder answers:** *What are the numbers, and which of them are real?*

## Canonical positions

- **BluePrint:** Core $399/mo · Growth $799/mo · $1,500 setup, per organization/office. `[A]`
- **Capital:** $950k capitalization envelope · $800k 18-month operating plan · staged against evidence gates. `[M]`
- **BlankCRM:** price open, blocked on COGS modelling. `[R]`
- **VAULTED:** 0.35% effective base take. `[A]`

## Rules

1. **Never blend the economic engines.** SaaS, marketplace take-rate and channel service revenue are different businesses. See [[../01_Canon/09 - Unit Economics Registry]].
2. **Never double-count software revenue** already counted inside a franchise or B_ Partner bundle.
3. **Never derive VAULTED revenue** from "all BluePrint customers × arbitrary GMV." Model the funnel.
4. **Publication gate:** every number needs a definition, a source/assumption label, owner approval and a matching model.
5. Per-offer economics live in each offer's `05 - Economics.md`; this folder holds the consolidated view.

## Heaviest evidence gaps `[R]`

Paid cohort retention/CAC · two independent development quotes · franchisee transaction economics · founder employment/EOR · vendor quotations (LMS, e-sign, messaging, AI, infra) · fully-loaded acquisition cost.
