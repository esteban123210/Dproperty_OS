# AI Layer Notes

AI should be added only after structured data and approved templates exist.

## Safe AI Uses

- Summarize client profile.
- Summarize project materials.
- Extract data from documents.
- Compare project options.
- Draft emails from approved templates.
- Create meeting summaries.
- Suggest next actions based on pipeline status.

## Risky AI Uses

- Creating legal clauses without review.
- Inventing financial assumptions.
- Generating unapproved investor projections.
- Making promises to clients.
- Modifying Private Collection materials.

## Principle

AI helps operate the system. It should not become the source of truth.
