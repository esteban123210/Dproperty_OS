# Dproperty Select

**Type:** **Strategic asset** — HQ-curated investment opportunity program. **Not a software product.**
**Job:** Provide differentiated, curated investment deal flow.
**Price:** Retained transaction commission. Historical baseline: **2.5%** payout to branded partner, **1.5%** to eligible own-brand partner. `[A]` Verify signed agreements.
**Status:** Active and operating. **Economics must be verified against signed agreements before investor or public use.**

Dproperty Select is Dproperty/B_'s HQ-curated investment opportunity program.

**Canonical name: Dproperty Select.** "Private Collection" is a legacy alias.

**The critical distinction from VAULTED:**
- **Dproperty Select = curated by us.** HQ controls what qualifies.
- **VAULTED = network marketplace.** Participation does not imply endorsement.

Select may appear inside VAULTED as a clearly identified curated collection, but **VAULTED never confers Select approval.**

**Governance:** HQ controls curation, approved assumptions, materials, access and commercial terms. Partners may propose opportunities but **cannot self-approve Select status.** Any public claim that franchisees curate the portfolio is incorrect and must be fixed.

## What it owns

Curation decisions and approval · approved assumptions and materials · access rights and tiering · commercial terms · partner payout structure

## What it does NOT own

Project/unit inventory as a system (→ developer system) · transaction execution (→ BlankCRM/chosen CRM) · marketplace mechanics (→ VAULTED) · the ledger

BluePrint may receive verified company-level financial/operating outcomes related to Select. It does not manage the inventory or execute the transaction.
