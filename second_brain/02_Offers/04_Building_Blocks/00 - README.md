# Building Blocks

**Type:** **Product** — standalone learning, onboarding and certification product. Powered by Open edX.
**Job:** Make capability transferable — convert operating standards into assigned, assessed, evidenced competence.
**Price:** $199 blended per enrollment `[A]` · certification $199–$349 `[A]` · enterprise cohorts quoted · core onboarding included in packages at allocated standalone value.
**Status:** Product architecture defined. **Cost base unquoted; standalone demand unvalidated.**

**Canonical name: Building Blocks.** Legacy aliases: *Academy*, *Building Blocks*, *Training Academy*.

## Why it is standalone

Every product in the portfolio is separately definable, priced and sellable — so that the franchise package is a **composition of named products**, not one monolith. Four strong products sell better than one product that "has it all." *(Decision 2026-09-24 — see [[../../01_Canon/19 - Portfolio Composition Principle]].)*

That cuts both ways: being a product means it must **stand on its own** — own ICP, own price, own economics, own P&L line.

## What it owns

Learning content and role-based curricula · course structure and learning paths · assignment and enrollment · assessments and scoring · **certification, expiry and renewal** · competency evidence · cohort and instructor management · the learner experience.

## What it does NOT own

Management or process truth → **BluePrint** · the process system of record — **never** · transaction execution, compliance sign-off, approvals → **BluePrint** · leads → **BlankCRM** · marketplace listings → **VAULTED** · **accredited formal qualifications** — no claim is made · licensed legal/compliance training where an accredited provider is required · daily transaction document storage.

## The differentiator — the closed loop

```
approved SOP → execution → BluePrint Glitch / process-health signal
   → capability gap identified → Building Blocks module or cohort
      → assessment + certification → BluePrint gates activation or privilege
         → outcome measured in BluePrint
```

**The loop is the moat, not the courseware.** Courseware is commodity; abundant free real-estate content exists. No LMS competitor has the operating-failure signal that drives enrollment, and no management-system competitor has the remediation path.

## Gaps — genuine, not placeholders

- **No LMS cost quotation.** `[R]` Open edX hosting, support and per-learner cost are unknown, so **gross margin cannot be stated**. Named evidence gap in [[../../01_Canon/13 - Status Dashboard]].
- **Content production and maintenance cost unmodelled.** `[R]` This is the biggest economic risk — see `05 - Economics`. Content behaves like a subscription cost, not a one-off build.
- **Standalone demand unvalidated.** `[A]` Nobody outside the ecosystem has been asked to pay. Until that happens, "standalone product" is design intent, not proven market.
- **`06 - Legal.md` missing.** Content IP ownership, certification claim limits and accreditation disclaimers are undocumented. Material exposure: the product issues certificates. `[R]`
- **Certification price range undefined** — $199–$349 is a placeholder spread.
- **Enterprise/developer cohort has no price structure**, only "quoted." Risk that it gets absorbed into the Developer Partnerships retainer for free.
- **Process→module dependency unmanaged.** When a process in `08_Operations/Process Library/` changes, the matching module goes stale and nothing currently detects it.
- **`04 - Product Record` and `07 - Investor Two-Pager`** still reflect the earlier framing in places and need a consistency pass against this README.

## Next gate

1. **Quote the LMS cost base** — this unblocks all economics.
2. Build core franchise onboarding curriculum only; do not expand the catalogue yet.
3. Prove **attach**: enrollments triggered by real BluePrint process signals, with existing customers.
4. Write `06 - Legal.md` before issuing any certificate externally.

**Do not invest in broad content production** until the cost base is quoted and attach is demonstrated. Bundled enablement is justified by franchise consistency and retention alone; standalone revenue must earn its own investment.

**Guardrail:** never imply accreditation, and never let Building Blocks become the process system of record.
