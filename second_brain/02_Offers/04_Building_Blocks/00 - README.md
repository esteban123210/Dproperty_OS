# Academy

**Type:** **Product** — enablement layer. Explicitly **not** a headline standalone business.
**Job:** Teach standards and close capability gaps.
**Price:** Mostly **bundled** into onboarding and channel packages. Premium/custom training possible later.
**Status:** Supporting layer. No standalone investment case, by decision.

Academy is the standards, training and certification layer of B_, powered by **Open edX**.

It is useful because BluePrint can connect real operating weaknesses to learning — not because an LMS is defensible IP. That is exactly why it stays a bundled layer.

**Naming:** *Academy* / *B_Academy* is canonical. `19_Canonical`'s **"Building Blocks"** is a legacy alias for the same learning business, resolved in favour of Academy on 2026-09-23.

**The closed loop:** process/SOP → execution → BluePrint Glitch/process-health signal → identified capability gap → Academy module/coaching → later operating outcome.

## What it owns

Learning content and курс structure · assessments · certification evidence · onboarding curriculum

## What it does NOT own

Management or process truth (→ BluePrint) · the process system of record — **Academy never becomes that** · transaction execution · compliance sign-off
