# 05_Pitch_and_Investor — How We Raise

**The question this folder answers:** *How do we raise, and what will a rigorous investor attack?*

## What lives here

| File | Purpose |
|---|---|
| `Pitch Deck Outline` | **Current** deck structure |
| `Pitch Script` *(archived)* | See `98_Archive/Superseded Pitch/` |
| `Founder Pitch to Dproperty Owners` | Internal pitch to existing owners |
| `Supervisor and Owner Q&A` | Anticipated questions |
| `Final Decks Index` | Where final deck files live |
| `Executive Summary - Seed Investment Case` | Seed case |
| `Investment Memo` | **Invest / do-not-invest judgment** |
| `IC Attack Sheet` | The hardest questions, pre-answered |
| `Data Room Index and Evidence Status` | What exists, what is missing |
| `Investor Two-Pagers Index` | Index to the per-offer two-pagers |

Each offer's two-pager lives with its offer: `02_Offers/0X_…/07 - Investor Two-Pager.md`.

## The honest current position

**Conditional pilot investment**, staged capital, explicit kill criteria.

**No file may imply** historical traction, signed pipeline, production security, independent legal approval or product-market fit until evidence exists. Diligence speed comes from exposing gaps, not hiding them.

## Before any investor conversation

Check that nothing retired appears: $299/$599/$999 · $650k or $1.5M ask · $500 blended ARPA · 600k TAM / 100k SAM · "5 franchises / 20 white-label / 15 developers" as company SOM · $1.59M–$1.89M Y5 as company forecast · physical hub as near-term thesis.
