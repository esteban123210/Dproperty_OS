# 98_Archive — Evidence Only

**The question this folder answers:** *What did we used to think, and why did we change?*

> [!WARNING] Never use anything here as current guidance
> Everything in this folder is **superseded**. It is preserved as evidence of how the thinking evolved, which is genuinely useful for diligence and for avoiding repeated mistakes. It is the **lowest** precedence in the vault.

## What is here

| Subfolder | Contents |

| `Parked/` | DpropertyLiving — parked concept |
| `Exports/` | Historical `.docx`, `.pptx`, `.xlsx`, `.zip` exports under legacy naming |

## Why these were superseded

Two events:

1. **2026-09-20 product reset** — the company changed from franchise-first to product-led operating infrastructure. Old TAM/SAM/SOM, the Y5 forecast, the $650k ask and the physical-hub thesis were retired.
2. **2026-09-23 canonical reconciliation** — two rival canonical layers were merged; BluePrint's definition, pricing, naming and the vault architecture were all fixed.

See [[../01_Canon/00 - Precedence and Canonical Reconciliation]].

## Rule

**Nothing is deleted.** If something here turns out to still be right, don't quietly promote it — write a decision record and move a corrected version into the live structure.
