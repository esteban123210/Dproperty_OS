**Status:** Canonical operating knowledge base

**Owner:** Founder/CEO until a knowledge owner is appointed

This repository is the operating memory for B_RealEstate and its commercial universe: B_Franchising, Dproperty, BluePrint, BlankCRM, Building Blocks, VAULTED, bfranchising.com, developer programs, and the shared data/AI foundation.

It has five jobs:

1. Give a founder, employee, developer, franchisee, adviser, investor, or AI system the same current definition of the business.
2. Separate facts, board decisions, modeled assumptions, targets, and unresolved questions.
3. Keep every product on one transaction spine without pretending they are one undifferentiated app.
4. Preserve auditability: source, owner, decision date, metric definition, and supersession history.
5. Make diligence fast by exposing missing evidence instead of hiding it.

## Truth labels

Every material claim should use one of these labels:

| Label | Meaning | May support spending? |
|---|---|---|
| `[F] Fact` | Verified actual result or executed agreement with evidence | Yes |
| `[D] Decision` | Approved management or board decision | Yes, within budget |
| `[M] Model` | Formula-driven output from a named financial model | Only with scenario context |
| `[A] Assumption` | Input not yet verified | Only through a gated experiment |
| `[T] Target` | Desired future state | No |
| `[R] Required evidence` | Missing proof necessary for a decision | No |

## Canonical doctrine

- BluePrint is the system of record from qualified opportunity through close, commission, and reporting.
- GoHighLevel/BlankCRM owns marketing, communications, appointments, and early pipeline—not transaction truth.
- Building Blocks owns learning content and certification evidence through an LMS; it does not own transaction execution.
- VAULTED owns gated opportunity access and distribution; it does not initially own custody, escrow, FX, or investment vehicles.
- Dproperty franchising is a controlled operating and distribution channel—not the definition of the software company.
- White-label partners share the same codebase and data model; branding and entitlements are configuration.
- Developer programs use the same project, inventory, distribution, transaction, and reporting spine.
- Copilot may retrieve, explain, summarize, draft, and propose. Binding or regulated actions remain human-authorized.
