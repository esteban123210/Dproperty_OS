# Borrowing Brilliance and Originality Method

This operating method adapts David Kord Murray's six-step innovation sequence—Define, Borrow, Combine, Incubate, Judge, Enhance—and the creative discipline associated with *Steal Like an Artist*: study many influences, transform them through context and craft, attribute sources, and never copy protected expression, code, brand, data, or trade secrets.

## 1. Define

Define the customer, high-friction job, present workaround, measurable outcome, constraints and non-goals. For B_: independent real-estate teams cannot reliably convert qualified demand into auditable transactions across CRM, documents, spreadsheets, chat and developer portals.

## 2. Borrow

Study proven patterns from adjacent domains:

| Source domain | Pattern worth studying | B_ translation |
|---|---|---|
| CRM | lifecycle, ownership, automation | qualified intake and status writeback |
| ERP/case management | system of record, controls, approvals | transaction workspace and audit |
| Data rooms | progressive access and evidence | VAULTED NDA/invitation states |
| Franchise systems | playbooks, territory, support, QA | Dproperty/partner operations |
| LMS/certification | assignments, completion, expiry | Building Blocks readiness gates |
| Marketplaces | supply quality, liquidity, attribution | narrow VAULTED corridor |
| Fintech controls | human approval, segregation, reconciliation | no silent compliance/payment action |

Borrow patterns, not interface copies or brand claims. Record source, license, what is generic, what is transformed, and IP review.

## 3. Combine

The novel combination is a transaction spine + configurable operating system + learning/readiness + gated inventory distribution + controlled franchise/partner channel. The combination is valuable only if it reduces handoff friction and creates an auditable outcome—not because it has many modules.

## 4. Incubate

Use time-boxed prototypes, design-partner shadowing, manual concierge pilots and decision pauses. Separate customer observation from solution advocacy. Keep a “not now” list so ideas can mature without entering the MVP.

## 5. Judge

Use evidence gates: severity/frequency of pain, willingness to pay, weekly use, retention, implementation effort, contribution margin, legal feasibility, data trust and channel repeatability. An investor-grade idea survives a red team and has explicit kill conditions.

## 6. Enhance

Improve the highest-friction step, remove unnecessary scope, instrument the workflow, tighten permissions, standardize implementation, and repeat. Enhancement should increase customer outcome or lower delivery cost—not merely add features.

## Originality/IP checklist

- Multiple inspirations, documented and attributed.
- No copied source code, proprietary content, customer lists, templates or confidential processes without rights.
- Trademark/domain clearance before brand commitment.
- Contractor/employee IP assignment and open-source inventory.
- Licensed datasets and content with allowed AI/training use recorded.
- User research artifacts consented and access-controlled.
- Design decisions explain B_'s contextual transformation.
