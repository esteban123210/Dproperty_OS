# First Franchisee Launch Playbook (Weeks 1-12)

**Goal:** First franchisee goes from signed agreement to €10k+ in commission revenue by end of Week 12.  
**Timeline:** 12 weeks (Sept 16 – Dec 8, 2026).  
**HQ support:** Weekly calls, coaching, operational support.  
**Success metric:** First deal closed by Week 8, minimum 3 deals in pipeline by Week 12.

## Part 2: Week-by-Week Launch Plan

### Week 1: Kickoff & System Onboarding (Sept 16-22)

**Franchisee Deliverables:**
- [ ] Attend Kickoff call (2 hrs, Esteban + tech team + finance)
  - Legal/tax/compliance overview
  - CRM walkthrough + test first lead entry
  - Brand guidelines review
  - Support structure + weekly call cadence
  - Q&A

- [ ] Complete CRM setup training (1 hr, with Miguel or tech lead)
  - Create first 3 test contacts (yourself, a friend, a prospect)
  - Create first lead pipeline (label your markets/prospects)
  - Set up automations (first follow-up email, SMS sequences)
  - Test API integrations (email → CRM sync)

- [ ] Set up GoHighLevel account (1 hr, with tech team)
  - Branding setup (colors, logo, fonts)
  - Create first landing page (lead capture for your target market)
  - Set up appointment calendar (link to your CRM)
  - Test from mobile (make sure it works for client-facing use)

- [ ] Personal network launch (3 hrs, independent work)
  - Create list of 100 contacts (personal network, past clients, friends, family)
  - Segment into: investors, entrepreneurs, expats, business owners, fellow brokers, etc.
  - Draft personal launch message (customized per segment)
  - Send first 20 messages (test the message, iterate if needed)

**HQ Support:**
- Kickoff call (2 hrs)
- Tech support (1 hr)
- Coaching on first 20 personal outreach messages (0.5 hrs async feedback)

**Success Metrics:**
- ✅ CRM fully operational (no errors, all features working)
- ✅ Personal network message sent to 20+ people
- ✅ First 5+ responses to personal outreach

---

### Week 2: Pipeline Building & Training Acceleration (Sept 23-29)

**Franchisee Deliverables:**
- [ ] Dproperty Select training session (2 hrs, with Esteban + Select team)
  - How Select deals work (deal flow, commission structure, HQ approval process)
  - Current deals available (overview of 3-5 current Select projects)
  - How to pitch a Select deal to clients
  - Rules: what franchisee can/cannot do (no unapproved projections, no direct developer contact, etc.)

- [ ] Sales playbook review session (1.5 hrs, with Esteban or sales coach)
  - Core scripts (first call, qualification, presentation, closing)
  - Weekly sales routine (Monday-Friday rhythm)
  - Objection handling
  - Role-play 1-2 scenarios

- [ ] Prospect pipeline building (5 hrs, independent work)
  - Expand personal network outreach to 100+ people
  - Follow up with Week 1 responses (schedule 5+ initial calls)
  - Begin broker outreach (if target market has brokers)
  - Create prospect tracking (who's interested, timeline, deal stage)

- [ ] Academy training (2 hrs assigned)
  - Dproperty Brand & Culture module
  - Dproperty OS Basics module

- [ ] Weekly HQ call (1 hr, Esteban)
  - Pipeline review (how many people are you talking to?)
  - Feedback on personal outreach messaging
  - Troubleshooting any CRM/tech issues
  - Coaching on discovery calls

**HQ Support:**
- Dproperty Select training (2 hrs)
- Sales playbook coaching (1.5 hrs)

- Async feedback on outreach (0.5 hrs)

**Success Metrics:**
- ✅ 100+ personal network messages sent
- ✅ 15-20 responses / interest signals
- ✅ 5+ discovery calls scheduled
- ✅ Compliance + sales training in progress

### Week 3: First Calls & Deal Identification (Sept 30 – Oct 6)

**Franchisee Deliverables:**
- [ ] Conduct 8-10 discovery calls (5 hrs)
  - Use discovery script from Sales Playbook
  - Qualify each prospect: investment appetite, timeline, market preference, budget
  - Log each call in CRM (contact details, key info, next steps)
  - Identify 3-5 "warm" prospects ready for project presentation

- [ ] Compliance certification (2 hrs)
  - Complete compliance certification module + quiz
  - Submit compliance acknowledgment to HQ
  - Review compliance checklist (advertising rules, data privacy, no-guarantee language)

- [ ] First project presentation (3 hrs)
  - Identify 1-2 projects for first presentations (either Dproperty Select or local opportunity)
  - Prepare presentation deck (using Dproperty template + local customization)
  - Run through presentation with Esteban (dry-run coaching)
  - Schedule presentation with warm lead (target: deliver by Week 4)

- [ ] CRM hygiene (2 hrs)
  - Clean up contacts from Week 1-2 (ensure all data correct)
  - Organize pipeline (stages: prospect, qualified, presenting, pending, closed)
  - Set up automated follow-ups (for leads that haven't responded)
  - Create forecast (how many deals likely to close by end of 2026?)

- [ ] Weekly HQ call (1 hr, Esteban)
  - Discovery call feedback (quality of conversations)
  - First presentation prep
  - Pipeline update
  - Any blockers/questions?

**HQ Support:**
- Compliance review (0.5 hrs)
- First presentation dry-run (1 hr)
- Weekly call (1 hr)

**Success Metrics:**
- ✅ 8-10 discovery calls completed
- ✅ 3-5 warm prospects identified
- ✅ Compliance certification complete
- ✅ First project presentation scheduled (target delivery Week 4)

### Week 4: First Presentation & Potential First Deal (Oct 7-13)

**Franchisee Deliverables:**
- [ ] Execute first project presentation (2 hrs)
  - Present to warm prospect(s)
  - Get feedback (timeline, interest, questions)
  - Follow up post-presentation (thank you, next steps, timeline)

- [ ] Continue discovery calls (5-8 more, 4 hrs)
  - Push pipeline forward
  - Identify any signals for early closing (prospects ready to move)

- [ ] First deal negotiation (if applicable, 2-3 hrs)

- [ ] Academy training (2 hrs assigned)
  - Client Advisory Certification module
  - Projection module (intro)

- [ ] Weekly HQ call (1 hr, Esteban + Franchisee + potential client, if applicable)
  - First presentation feedback

**HQ Support:**
- First presentation feedback + coaching (0.5 hrs)

## Part 3: HQ Support Structure

### Weekly Accountability Call (Every Monday, 1 hr)

**Agenda:**
1. **Pipeline review** (15 min)
   - How many prospects are you talking to?
   - What's in closed deals? Active pipeline? Pending?
   - Any deals stalling? Why?

2. **Deal coaching** (20 min)
   - Walk through 1-2 deals in progress
   - Any obstacles?
   - Are you following the playbook?
   - Next steps?

3. **Prospecting feedback** (15 min)
   - How are discovery calls going?
   - Any objection patterns?
   - Messaging tweaks needed?

4. **Blockers & support** (10 min)
   - Technical issues (CRM, software, etc.)?
   - Operational questions (compliance, legal, etc.)?
   - Personal coaching needs?

**Attendees:** Esteban (HQ) + Franchisee (+ Miguel if tech issues)

---

### Ad-Hoc Support

- **CRM troubleshooting** (tech team, same-day response)
- **Legal/compliance questions** (Esteban or lawyer, within 48 hrs)
- **Sales coaching** (Esteban, async or scheduled)

## Part 6: Risk Mitigation & Contingency Plans

### Red Flag: Franchisee Not Getting Pipeline (by Week 4)

**Signs:**
- Fewer than 10 discovery calls completed by Week 4
- 0 deals in pipeline
- Messaging not resonating with prospects

**Intervention:**
1. Review Week 3-4 calls with franchisee (listen to 1-2 recordings)
2. Provide specific feedback on discovery call quality
3. Adjust messaging + target market if needed
4. Introduce franchisee to 3-5 warm leads from HQ network (jumpstart pipeline)
5. Increase coaching intensity (2x per week calls instead of 1x)

**Decision point (Week 6):** If still no pipeline, assess fit (is franchisee coachable? Did we target wrong market? Wrong person?)

---

### Red Flag: First Deal Taking Longer Than 6 Weeks

**Signs:**
- Warm prospects not moving forward
- Feedback: "Still thinking," "need to talk to spouse," "need financing"

**Intervention:**
1. Join calls with franchisee + prospect (assess sales approach)
2. Provide deal-closing coaching
3. Expedite financing/legal support (remove obstacles)
4. Introduce Dproperty Select deal (easier close, HQ manages)
5. Extend timeline expectations (some markets move slower; that's okay)

**Decision point (Week 8):** If still no close, consider market fit or franchisee sales skills.

---

### Red Flag: Franchisee Wants to Modify System / Skip Steps

**Signs:**
- "I want to do my own CRM instead of GoHighLevel"
- "The sales playbook doesn't work in my market; I'm doing it my way"
- "I don't want to participate in Dproperty Select"

**Response:**
1. Clarify franchise agreement: system is non-negotiable (that's why they pay for it)
2. Understand the concern: is the system truly not working, or is franchisee just impatient?
3. Test together: use the system as designed for 4 weeks, measure results
4. If system truly not working for market, iterate together (but with HQ approval, not franchisee unilaterally)

**Decision point (Week 4-6):** If franchisee refuses to follow system, this is a culture/values fit issue. May signal future trouble.
