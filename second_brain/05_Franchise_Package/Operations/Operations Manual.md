# Operations Manual

## Purpose

This manual defines how a Dproperty franchise operates day to day.

## Core Operating Principles

- Every client must be registered.
- Every broker relationship must be documented.
- Every project presentation should use approved materials.
- Every projection must use approved assumptions.
- Every deal must be tracked in Dproperty OS/CRM.
- Every commission split must be recorded.
- Every Private Collection opportunity must follow HQ rules.

## Daily Routine

- Check CRM tasks.
- Follow up with active leads.
- Update deal statuses.
- Respond to client/broker messages.
- Record new notes in Dproperty OS.

## Weekly Routine

- Review pipeline.
- Review broker outreach.
- Review active projects.
- Report new opportunities to HQ.
- Update forecast.
- Complete training actions.

## Monthly Routine

- Submit royalty/commission report.
- Review marketing performance.
- Review compliance items.
- Update local market notes.
- Join HQ review call.

## Required Systems

- Dproperty OS.
- GoHighLevel/CRM.
- Official file library.
- Approved templates.
- Training academy.
