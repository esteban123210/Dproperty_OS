# Compliance Package

## Purpose

Protect the brand, clients, HQ relationships, and franchise network.

## Compliance Areas

- Brand usage.
- Data privacy.
- Client registration.
- Broker agreements.
- Developer/project approvals.
- Private Collection access.
- Projection assumptions.
- Marketing claims.
- Commission reporting.
- Legal document usage.

## Franchisee Must Not

- Use unapproved project materials.
- Modify Private Collection materials.
- Make guaranteed return claims.
- Bypass HQ on controlled inventory.
- Hide deals.
- Ignore CRM/reporting obligations.
- Use the brand in a way that damages trust.

## Review Rhythm

- Monthly compliance review during first 90 days.
- Quarterly review after launch.
- Immediate review for Private Collection issues.
