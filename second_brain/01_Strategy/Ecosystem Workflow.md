# Ecosystem Workflow

> **Naming note (2026-07-14):** This note is about the **tooling ecosystem** (which app does what). It is NOT the business "ecosystem vision" (the 19M/Station F physical hub). For the business ecosystem, see [[Ecosystem Deck Outline]] and [[Pitch Deck Outline]]. Kept separate deliberately to avoid confusion.

## Tool Roles

- Obsidian: source of truth, decisions, context, notes, manuals, specs, links.
- Deliverables Tracker: execution status and missing documents.
- SharePoint/Drive: official file storage for final/heavy files.
- Figma: product prototype and visual flows.
- Excel/Sheets: financial models and trackers.
- ChatGPT: strategy, finance, documents, structure, reasoning.
- Claude: long-form polish, UX copy, design/code prompts.
- PowerPoint/Canva/Adobe: final visual assets and decks.
- GoHighLevel: CRM and marketing automation.
- Dproperty OS: final operational product.

## Work Session Workflow

1. Check tracker.
2. Open related Obsidian note.
3. Work in the right tool.
4. Save final/heavy files externally.
5. Link files in Obsidian.
6. Update decision log and open questions.
7. Update tracker.
8. Create session closeout note.

## Rule

If it explains, decides, structures, or links: Obsidian.  
If it is a final asset, signed file, heavy media, or designed file: SharePoint/Drive/Figma/Canva.  
If it calculates: Excel/Sheets.  
If it operates live leads: GoHighLevel/Dproperty OS.
