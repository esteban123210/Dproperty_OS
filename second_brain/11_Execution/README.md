# 11_Execution — What I Am Doing Now

**The question this folder answers:** *What am I doing this week, and what is the status of everything?*

## What lives here

| File | Purpose |
|---|---|
| `Deliverables Tracker - Compact MD` | **The execution tracker** — what exists, status, owner, next action |
| `Deliverables Tracker - MVP Only` | MVP-scoped subset |
| `Current Sprint` | Active sprint |
| `Weekly Review Workflow` | The weekly rhythm |
| `Phased Rollout - Product and GTM` | Phased rollout plan |

Strategic priorities live in [[../00_Start_Here/Current Priorities]]. This folder is *execution*, not priority-setting.

## The tracker is the execution source of truth

Obsidian holds thinking and decisions. The Deliverables Tracker holds **status**. When a deliverable changes state, the tracker is updated in the same session.

## Note on archived roadmaps

The July–September 2026 weekly roadmaps, sprint plans and per-person task lists are in `98_Archive/Superseded Execution/`. They were built on the franchise-first plan and are kept as evidence of what was attempted, not as current instructions.
