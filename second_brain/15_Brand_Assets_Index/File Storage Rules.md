# File Storage Rules

## Obsidian

Use for:

- Notes.
- Strategy.
- Manuals.
- Specs.
- Context.
- Links.
- Small reference files.

## SharePoint/Drive

Use for:

- Final decks.
- Heavy PDFs.
- Legal files.
- Signed contracts.
- Brand assets.
- Videos.
- Brochures.
- Final templates.

## Figma

Use for:

- Product prototype.
- Wireframes.
- Design system.
- UI components.

## Excel/Sheets

Use for:

- Financial models.
- Deliverables tracker.
- Pricing calculators.

## Rule

Every important external file should have an Obsidian index note with its official link, version, owner, and status.
