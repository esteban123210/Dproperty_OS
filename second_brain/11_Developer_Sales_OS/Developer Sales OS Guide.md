# Developer Sales OS Guide

## Purpose

Developer Sales OS helps developers sell projects more professionally without building a full sales operating system from scratch.

## What Dproperty Provides

- CRM/pipeline setup.
- Sales process.
- Team training.
- Broker activation.
- Sales scripts.
- Reporting dashboard.
- Weekly pipeline review.
- Project presentation framework.
- Investor projection support.
- Dproperty/network client access.

## Target Developers

- Good project, weak sales process.
- No internal sales manager.
- Need international/boutique buyer access.
- Need broker discipline.
- Need reporting to leadership/investors.

## Offer Levels

1. Sales Enablement.
2. Managed Sales Desk.
3. Exclusive Project Sales Partner.
