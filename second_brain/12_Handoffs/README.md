# 12_Handoffs — Tool-Ready Production Briefs

**The question this folder answers:** *How do I get an external tool to produce the finished artifact?*

## What a handoff is

One **self-contained** file per deliverable: final content **plus** design/brand direction, assets list and copy-paste tool instructions — so an external tool (deck builder, website builder, print layout, spreadsheet) can produce the highest-fidelity artifact from that single file.

**Inline everything.** External tools cannot follow wikilinks.

## Required sections

Production Brief · Design/Brand Direction · Assets Required · Tool Instructions · Final Content · Build & QA Checklist · Source & Change Log

Template: `_Handoff Template.md` · Index: `00 - Handoff Index.md`

## The precedence rule

**If a handoff and its source note disagree, the source note wins and the handoff is regenerated.** A handoff is a derived artifact, never a source of truth.
