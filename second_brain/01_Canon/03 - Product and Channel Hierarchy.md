# Product and Channel Hierarchy

## Products

1. **BluePrint — RUN THE COMPANY** (qualified opportunity → transaction → commission → control → audit)
2. **BlankCRM — SELL** (demand → qualification)
3. **VAULTED — ACCESS THE NETWORK**
4. **Academy — OPERATE BETTER** (legacy alias: Building Blocks)

## Channels/packages

- **Direct SaaS** — BluePrint and/or BlankCRM.
- **B_ Partner** — managed stack under customer's brand.
- **Dproperty Franchise** — branded full operating model.
- **Developer Partnerships** — developer commercial/supply relationship.

## Strategic assets, not products

Dproperty Select, Dproperty brand, Second Brain/process library, developer/broker/investor relationships.

## Core proprietary vs rented infrastructure

**Proprietary/strategic:** BluePrint product/data model; VAULTED network/attribution; operating standards/ontology; brand/network relationships.

**Third-party infrastructure:** GoHighLevel, Open edX, accounting providers, bank/payment providers, file storage, e-signature, foundation-model APIs.

## Pitch rule

Never present all boxes as equal businesses. The hierarchy is:
**BluePrint core SaaS → VAULTED network upside → BlankCRM attach → channels/enablement.**
