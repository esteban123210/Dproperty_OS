# Glossary and Core Metric Dictionary

| Term | Canonical definition |
|---|---|
| B_RealEstate | Neutral company/software ecosystem |
| B_Franchising | Commercial/operating partnership gateway and support **function** — never the definition of the company |
| B_ Partner | **Canonical name** for the managed own-brand channel; *White-Label* is a legacy alias |
| Dproperty Select | **Canonical name** for HQ-curated opportunities; *Private Collection* is a legacy alias |
| Developer Partnerships | **Canonical name** for the developer channel; *Developer Sales OS* is a legacy alias |
| Dproperty | Branded brokerage/franchise operating model |
| BluePrint | Post-qualification transaction/back-office system of record **and** management-control layer: transaction file, compliance, approvals, closing, commission calculation, budgets/variance, process assurance, Glitches, period close, audit. Never property/unit inventory, listings or MLS |
| BlankCRM | Managed GoHighLevel-based front-office package |
| Academy / B_Academy | **Canonical name** for the learning/onboarding/certification layer, powered by Open edX; mostly bundled. *Building Blocks* is a legacy alias (corrected 2026-09-23) |
| VAULTED | Gated opportunity, deal-room and distribution module |
| GCI | Commission actually collected and retained by agency after external co-broker shares/refunds and excluding indirect tax, before internal agent payouts |
| GMV | Completed attributable property transaction value; not revenue |
| ARR | Current recurring software subscription run-rate; excludes setup, entry, restricted funds, course enrollments, pass-through and uncontracted usage |
| Active organization | Contracted production tenant with qualifying use during period; exact event threshold set in metric version |
| Active franchise | Open production office under effective agreement; signed/unopened is separate |
| Qualified opportunity | Meets configured minimum data/consent/intent and is accepted for transaction workflow |
| Completed transaction | Reaches configured closing criteria with required evidence and no unresolved mandatory control |
| Attributable transaction | Source and participation are documented under an agreed attribution rule and confirmed by required parties |
| Restricted fund | Collected for contractually defined network/brand use; segregated and excluded from operating EBITDA |
| Logo retention | Beginning eligible customers retained ÷ beginning eligible customers |
| Gross revenue retention | Beginning recurring revenue retained excluding expansion ÷ beginning recurring revenue |
| CAC | Fully loaded acquisition spend for acquired paying customers, including labor/tools/failed spend |
| CAC payback | CAC ÷ monthly gross-margin contribution from the acquired cohort |
| Implementation hours | Direct internal/contractor hours from approved kickoff to production activation; custom work separately tagged |
| Weekly active target user | User in defined role performing a qualifying value event within week |
| Support capacity | Staffed productive support/implementation hours minus forecast demand and operational reserve |

Every metric implementation records formula version, source events/tables, inclusions, exclusions, grain, timezone, currency, owner and effective date.
